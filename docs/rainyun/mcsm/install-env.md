# 安装运行环境

本页说明如何在雨云游戏云中选择与服务端文件相匹配的 Java 和服务端环境。

## 进入游戏云面板
依次进入 `云产品` → `游戏云` → `管理`。

## 安装基础环境  

::: tip 环境选择原则
- 如果服务端压缩包已经包含 Forge、NeoForge 或 Fabric 核心，并带有完整的 `libraries/` 目录或核心文件，请安装`纯 Java 环境`。
- 如果服务端文件不包含核心，请安装与游戏版本匹配的`基础端`。
- 如果列表中没有所需的基础端版本，可参考[视频教程](https://www.bilibili.com/video/BV1GTUhBfETs/)手动安装相应核心，并改用`纯 Java 环境`。
:::  

1. 在雨云面板顶部找到`重装 / 更新游戏`。
2. 根据服务端文件选择环境：
   - 未包含核心：重装为`对应游戏版本的对应核心`。
   - 已包含核心：重装为`纯 Java 环境`。
3. 如果安装的是纯 Java 环境，后续必须在`文件管理`的 `server.properties` 中修改 `server-port`。端口值应与`雨云面板` → `NAT 端口映射管理` → `对外地址:端口`显示的端口数字一致，否则客户端无法连接。


::: info Java 版本参考

| 游戏版本 | Java 版本 |
| :----: | :---: |
| 1.7～1.15.2 | Java 8 |
| 1.16.5 | Java 11 |
| 1.17～1.20.x | Java 17 |
| 1.20～1.21.x | Java 21 |
| 26.1～最新版本 | Java 25 |

如整合包作者明确指定 Java 版本，应优先遵循整合包说明。
:::
