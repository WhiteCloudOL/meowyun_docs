# 雨云 MCSManager 面板

本系列文档介绍如何使用雨云游戏云和 MCSManager（下文简称 MCSM）面板部署并管理游戏服务端。

- **雨云注册链接：** <https://www.rainyun.com/qzyy_>

::: warning  
该面板适用于 Minecraft、饥荒、泰拉瑞亚和僵尸毁灭工程等游戏开服。单个面板只能运行一个服务端；如需单机多开或同时运行其他程序，应选择自由度更高的`游戏云 VPS`。
:::  

::: info 界面名称
- **雨云面板：** `云产品` → `游戏云` → `管理`
- **MCSM 面板：** `云产品` → `游戏云` → `管理` → 左上角“进入控制台（MCSM）”
:::

面板支持一键开服、网页可视化管理和 SFTP 文件传输，适合初次搭建服务端或仅运行单个实例的场景。雨云面板与 MCSM 面板的主要操作流程相近；部分功能可直接在雨云面板完成，无需进入 MCSM。
