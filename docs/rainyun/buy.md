## 确认需求
购买前应先确认是否确实需要长期运行的服务器。如果参与人数很少且游玩频率较低，也可以考虑通过**内网穿透或虚拟局域网**联机，例如 Sakura FRP。此类产品要求用户年满 18 周岁。

如果需要持续在线、稳定公网访问或更完整的管理能力，可继续根据下文选择服务器。

## 服务器类型选择
### 云服务器

适合搭建网站和运行通用应用。

### 游戏云 VPS

提供完整的独立操作系统，可安装 Windows Server 或多种 Linux 发行版。

- **优点：** 自定义能力强，可安装额外应用；游戏性能通常优于同档通用云服务器。
- **缺点：** 需要掌握系统环境安装、远程连接和基础运维。

### 游戏云面板

提供面向游戏开服的专用管理面板。

- **优点：** 操作简单，适合初次开服，价格通常低于 VPS。
- **缺点：** 自定义能力有限，不能运行其他应用，单台产品通常只能运行一个实例。

::: tip  
以下为 **Minecraft 服务器**选购建议，适用于`游戏云 VPS`和`游戏云面板`。
:::

## 其他选配建议
1. **核心数量：** 内存小于 8 GB 时建议选择`2 核心`；大于 8 GB 时建议选择`4 或 6 核心`。Minecraft 服务器更依赖单核性能，核心数量并非越多越好。
2. **内存大小：** 参考上方表格，并为系统、Java 和备份任务预留空间。
3. **硬盘：** 建议至少选择 `20～30 GB`。如需保留多个备份、安装大量 Mod 或进行大范围跑图，应适当增加容量。
4. **对外端口：** 保持默认配置即可，购买后再根据面板提供的映射端口修改服务端设置。
5. **面板账户：** 选择自动创建。
6. **游戏类型：** 可选择任意类型，后续仍可按照实际服务端进行配置。
