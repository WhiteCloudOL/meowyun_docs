# 雨云注册与登录

本页介绍雨云账号的注册、登录和基础账户设置流程。

## 注册账号

1. 打开[雨云官网](https://www.rainyun.com/qzyy_)。
2. 点击页面右上角的“注册 / 登录”，输入用户名和密码完成注册。
3. 注册完成后，点击右上角头像并进入“账户设置”。
4. 按页面提示完成微信绑定和实名认证，即可获得原页面说明的`首月 5 折券`。

::: info 优惠说明
使用优惠码 `qzyy` 可享受首月 5 折、续费 7～9 折，并可叠加原有优惠。具体优惠条件、有效期和可用产品请以雨云官网结算页面为准。
:::

::: warning 账号安全
请使用唯一且强度足够的密码，并妥善保管实名认证信息。任何客服或协助人员都不应向你索要账号密码。
:::
