# MaiBot（麦麦）

MaiBot 是一款开源智能聊天机器人，致力于为 QQ 等社交平台提供**深度拟人化**的交互体验。通过多模型协同与仿生思考架构，MaiBot 能够实现自然、流畅且富有深度的对话。

---

### 🚀 快速上手
如果您是初次接触，建议按照以下步骤进行：

1. **部署准备**：阅读 [安装与部署](/qqbot/maibot/install) 快速搭建服务。
2. **个性化配置**：参考 [配置概览](/qqbot/maibot/config/conf) 完成模型与人格设定。
3. **连接方案**：支持 [普通 QQ 账号](/qqbot/maibot/adapters/onebot) 或 [QQ 官方机器人](/qqbot/maibot/adapters/qq-official) 等多种接入方式。
4. **日常进阶**：更多使用技巧请查看 [使用指南](/qqbot/maibot/usage/use)。
