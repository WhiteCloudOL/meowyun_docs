# WebUI 使用指南

完成 [基础配置](/qqbot/maibot/config/conf) 后，您可以通过 WebUI 直观地管理机器人、监控状态及调整运行策略。

---

## 🧭 界面导航概览

WebUI 侧边栏集成了各项管理功能。若界面显示图标，将鼠标悬停即可查看完整名称：

| 管理模块 | 主要功能 |
| :--- | :--- |
| **麦麦设置** | 修改昵称、性格、表达风格及交互频率 |
| **模型管理** | 管理 API Key、添加模型及分配任务分工 |
| **适配器设置** | 配置 QQ 连接，管理允许参与的群聊/私聊名单 |
| **学习** | 查看与调整机器人的表达库、黑话学习 |
| **长期记忆** | 查看与管理机器人的记忆内容 |
| **插件扩展/市场** | 配置已安装功能插件，或搜索安装新扩展 |
| **日志** | 监控运行状态，排查报错或连接异常 |
| **数据管理** | 导出数据、查看存储空间占用 |

---

## 🤖 多机器人切换

点击侧边栏底部的 `当前 Bot` 按钮，可进行机器人切换。

- **作用域说明**：
    - **独享数据**：麦麦设置、聊天记录、记忆及适配器规则均随所选机器人切换。
    - **共享资源**：模型库（厂商、API Key、模型列表）由工作区内所有机器人共用。修改厂商密钥将影响使用该厂商的机器人。
    - **差异化分配**：在“模型分工”中，您可以为不同机器人分配独立的模型任务。

---

## 💬 对话管理与策略

在 `所有对话` 列表中，您可以进入指定会话并点击设置图标进行精细化调整：

- **调整活跃度**：通过 `麦麦设置` -> `回复节奏` 动态调整群聊/私聊的回复频率。
- **@消息响应**：群聊中需要通过 @触发回复时，开启 `At 必回复`。
- **限制参与范围**：在 `适配器设置` 中的 `黑白名单规则`，精确控制机器人运行的群组或私聊对象（详见 [群聊与私聊规则](/qqbot/maibot/adapters/adapter-policy)）。
- **标识显示**：使用官方机器人时，若会话显示为 OpenID，可参考 [QQ 号绑定](/qqbot/maibot/adapters/qq-identity) 同步真实群号或 QQ 号。

## ⚙️ 维护与生效说明

- **实时生效**：人格设定、模型任务分配及接收规则调整后，系统会自动应用。
- **需重启生效**：修改监听地址、端口或 HTTPS 等底层网络配置后，务必重启 MaiBot 服务。具体查看 [配置文件生效说明](/qqbot/maibot/config/configuration-files#配置生效方式)。
