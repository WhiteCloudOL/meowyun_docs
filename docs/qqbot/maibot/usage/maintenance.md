# 备份与更新

更新程序或迁移服务器前，先备份工作区共享设置和各机器人的独立数据。

## 备份与恢复

更新前，先在 MaiBot Manager TUI 的 `核心服务管理` 中停止 MaiBot，再复制需要保留的文件到单独的备份文件夹。

建议一起备份：

- 工作区的 `host/`：保存共用模型、管理页面密码和机器人登记信息。
- 每个机器人目录下的 `config/`：保存人格、模型分工和适配器配置。
- 每个机器人目录下的 `data/`：保存聊天、记忆及插件数据。
- 每个机器人目录下的 `plugins/`：保存已安装的第三方插件。

新安装的机器人通常在 `bots/<Bot ID>/` 下；从旧版升级的机器人可能仍直接在 MaiBot 安装目录中。目录说明见 [配置文件与目录](/qqbot/maibot/config/configuration-files)。

需要恢复时，先停止 MaiBot，再将同一份备份中的文件放回原位置，最后启动并检查机器人、模型和聊天记录是否齐全。

## 更新 MaiBot

1. 按上一节完成备份。
2. 打开 MaiBot Manager TUI 的 `部署与更新`，更新当前安装。
3. 启动 MaiBot，查看日志中是否有需要确认的升级提示。
4. 登录管理页面，确认模型分工和适配器连接正常。
5. 在测试会话发一条消息，确认麦麦能够回复。

内置的 QQ 官方机器人适配器随 MaiBot 一起更新。第三方插件在插件市场或插件管理中分别更新，操作见 [插件安装与配置](/qqbot/maibot/usage/plugins)。
